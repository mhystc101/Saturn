# Saturn
Hermes Ai agent isolated with docker powered with Omniroute, made by Diego Rodrigues, optimized with caveman. 




Goal: Scans clearnet and darknet for similarities between two users. Using texting style, common words, timezone, and PGP keys (although unlikely match) using premade tool, but added self-learning with the attribute of Hermes.

Current: Isolated on burner laptop with docker, controlled via ssh from main. Omniroute and caveman implemented.



References: Omniroute: <a>https://github.com/diegosouzapw</a>  Caveman: <a>https://github.com/JuliusBrussee/caveman</a>
